What Safari changes

01 / THIRD-PARTY

Cross-site storage is restricted

Safari blocks third-party cookies by default. SameSite=None does not bypass ITP.

02 / SCRIPT STORAGE

Seven days is conditional

Script-created cookies and other script-writable storage can be removed after seven days without user interaction, measured in days of Safari use.

03 / TRACKING CONTEXT

Some limits need browser evidence

Link decoration and cloaked tracking can trigger shorter limits. A header scan cannot determine tracking classification or user interaction history.

Browser evidence, with clear boundaries.

Browser scans execute JavaScript in a fresh Chromium session and capture scripts, network requests, cookie metadata, and storage keys. Add a consent button selector to compare snapshots. Blocked resources are listed explicitly. Chromium does not reproduce Safari ITP, and a single page scan does not discover all tracking across a site.
